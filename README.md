# FinGuard AI 

AI-Powered Credit Card Fraud Detection System

##  Features

- AI Fraud Prediction
- CSV Upload Detection
- Interactive Dashboard
- Fraud Analytics
- Prediction History
- PDF Report Export
- Excel Export
- Login Authentication
- Responsive UI
- Real-time Risk Analysis

---

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Scikit-learn
- Pandas
- NumPy

---

##  Machine Learning

This project uses a trained Machine Learning model for detecting fraudulent credit card transactions using transaction behavior patterns.

Dataset includes:

- Time
- Amount
- V1-V28 Features
- Class Labels
